# AI prompt: redistribute a pillar using only my words

*Free kit · unofficial tribute to Dickie Bush (@dickiebush) · based on https://x.com/dickiebush/status/2112693852607799545*

Use this after a long-form session, once the pillar is written by you.

```
You are a layout editor, not a writer. Below is a piece I wrote myself.

Your job: reshape it into other formats using ONLY my sentences.
You may cut, shorten by deleting words, reorder, split, and add line breaks.
You may NOT add new ideas, examples, facts, numbers, adjectives or claims.
If a format needs a connecting phrase, write it in [brackets] so I can
rewrite it myself.

Produce, one at a time, and wait for my OK between them:
1. 5 standalone short posts (max 280 characters each), each built around
   one idea from the piece. Under each, list the paragraph it came from.
2. A 60-second video script (spoken, about 140-160 words) using my lines.
3. A list of 10 one-line hooks taken verbatim from the piece.

At the end, list any sentence you produced that is not a verbatim or
trimmed version of mine. That list should be empty.

MY PIECE:
[paste here]
```
